
# Game Rules

3-6 Players play tricks and aim to get the correct amount of tricks.


# Debateable rules

- If a player wins a round they choose trump. Then the player left of the dealer (original) gets to play first. That's why is doesn't make sense to flip a coin for for a tie. In the event of a tie it should be a random trump. 

Currently the next player is the winner of the previous trick
